# 🍭 The Dramatic Narrator & Server Historian\n\nA theatrical, over-the-top Discord bot powered by Google Gemini or OpenAI that roleplays as an omniscient narrator documenting your server's chaotic shenanigans, archiving out-of-context quotes, playing trivia, and powering a fun server economy.\n\n---\n\n## ✫ Features & Capabilities\n\n### 1. 🎸 The Dramatic Recap & Roasts\n- **/recap [style] [limit]**:\n  Summarizes recent chat in hilarious, easy-to-read bullet points across 5 distinct comedy styles:\n  - 🥷 **Reality TV Confessional** (Love Island / Real Housewives messy drama)\n  - ☘️ **Courtroom Trial** (Judge Judy hearing petty crimes against chat)\n  - 🚀 **Breaking News Broadcast** (Live emergency anchors covering silly arguments)\n  - 🌰 **Medieval Fantasy Drama** (Game of Thrones parody in clear modern English)\n  - 🎯 **Nature Documentary** (David Attenborough scientifically observing wild Discord creatures)\n- **/roast @friend[spice]**:\n  Delivers a short (2-4 sentences), punchy, and hilarious roast based directly on their recent chat habits.\n- **/chronicle** & **/lore**:\n  Record and recall legendary server moments from the Sacred Archives.\n\n---\n\n### 2. 💸 The "Out of Context" Quote Vault\n- **Emoji Capture**: Whenever someone says something hilarious or bizarre, react to the message with 📸 or 💬. The bot automatically archives the quote, author, jump URL, and capturer into SQLite.\n- **/quote**: Resurfaces a random out-of-context gem from the vault.\n- **/quoteleaderboard**: Displays the server's most quoted legends.\n- **/whosaidit**: Interactive trivia mini-game! Guess which friend uttered the quote using interactive buttons. Correct guesses win 100 Gold Coins!\n- **/setflashback #channel**: Designates a channel where the bot automatically posts a Daily Flashback quote every morning.\n\n---\n\n### 3. 💰 Server Economy & Custom Black Market Shop\n- **Earn Coins**:\n  - Chatting actively (+5 coins per minute)\n  - Claiming your daily allowance via **/daily** (+250 coins)\n  - Winning Quote Trivia in **/whosaidit** (+100 coins)\n- **/balance [@user]**: Check your coin balance.\n- **/rich**: Displays the server's wealthiest citizens.\n- **/shop**: Browse hilarious perks you can purchase:\n  - 🏷️ **/buy_rename @friend [new_name]** (500 Coins) - Change a friend's nickname for 24 hours (auto-reverts!).\n  - 🤰 **/buy_vcmute @friend** (350 Coins) - Mutes a friend in voice chat for 2 minutes (auto-unmutes!).\n  - 👌 **/buy_pin [message_id]** (250 Coins) - Pins any hilarious message to the channel.\n  - 🎨 **/buy_role [role_name] [hex_color]** (1000 Coins) - Creates and assigns a custom vanity role.\n\n---\n\n## 🚀 Setup & Installation\n\n### 1. Requirements\n- Python 3.10+\n- Discord Bot Token with Message Content Intent enabled.\n- Google Gemini API Key or OpenAI API Key.\n\n### 2. Discord Developer Portal Permissions\n- *Scopes*: `bot`, `applications.commands`\n- *Bot Permissions*:\n  - `View Channels`, `Send Messages`, `Read Message History`, `Embed Links`, `Add Reactions`, `Use External Emojis`\n  - `Manage Nicknames` (needed for buy_rename)\n  - `Mute Members` (needed for buy_vcmute)\n  - `Manage Roles` (needed for buy_role)\n  - `Manage Messages` (needed for buy_pin)\n- *Privileged Gateway Intents*:\n  - ✑ **Message Content Intent** (Required)\n\n### 3. Installation\n```bash\npip install -r requirements.txt\ncp .env.example .env\npython bot.py\n```\n
